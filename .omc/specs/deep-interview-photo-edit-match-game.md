## Goal
사진 보정을 **게임처럼 연습하는 학습 도구**. 플레이어는 원본 사진과 정답(보정된) 사진을 보고, Lightroom 호환 글로벌 파라미터와 자체 마스크·크롭을 가진 웹 에디터로 원본을 정답과 같아지도록 보정한다. 제출하면 결정적 참조 렌더로 만든 결과 이미지와 정답 이미지의 지각 색차를 **평가 영역** 안에서 비교해 0~100점의 **보정 점수**(원본 그대로 = 0, 지각적 동일 = 100)와 톤·색·디테일·로컬·구도 5개 **진단 지표**를 받고, 정답 레시피 해설과 영역별 관측 문장으로 무엇이 달랐는지 배운다. 점수는 스포일러 없는 카드 이미지로 카카오톡 등에 공유해 친구가 같은 챌린지를 플레이하게 한다. 백엔드 없이 정적 호스팅으로 동작하며 데스크톱·모바일 모두 지원한다.

## Constraints

### 플랫폼 / 아키텍처
- 반응형 웹, 데스크톱 + 모바일 v1 동시 지원. 마스크 UX는 마우스와 터치 모두.
- 백엔드 없음. 정적 호스팅 + 클라이언트 렌더·채점·카드 생성. 진행/베스트/초안은 localStorage.
- **렌더 이원화**: 정답 생성·제출 렌더·채점은 **CPU/WASM 참조 구현**(결정성의 유일한 기준). GPU(WebGL2/WebGPU)는 조작 중 **프리뷰 전용**이며 점수 계약에 포함되지 않는다. 제출 전에는 참조 렌더 결과를 표시한다.
- 참조 렌더는 float32 중간값, 최종 출력에서만 8bit 양자화. 수학 함수는 WASM 바이너리에 포함(플랫폼 libm 의존 금지), 완화된 부동소수 최적화·비결정적 병렬 합산 금지.
- 렌더 순서 고정: 입력 정규화 → 글로벌 보정 → 범위 마스크 평가 → 마스크 합성 → 디테일 효과(샤프닝·그레인) → 최종 색공간 변환.
- 성능 기준 기기: **iPhone 12 Safari, Galaxy A54 Chrome**. 프리뷰 프레임 p50 ≤ 33.3ms / p95 ≤ 66.7ms, 입력 지연 p95 ≤ 100ms, 제출~채점 완료 p95 ≤ 2초 (출시 조건. 실패 시 해상도·효과 범위 재결정).

### 해상도 파이프라인
- 원본: EXIF 방향 적용 SDR sRGB **2048px(장변) JPEG q90** 정적 서빙. 매니페스트에 원본 해시·정규화 자산 해시 기록.
- 프리뷰: 뷰포트 크기 GPU 렌더.
- **채점 이미지: 2048px 참조 렌더 → 선형광 Lanczos3로 1024px 축소**(커널 반경·경계 확장·픽셀 중심·반올림 규칙 고정). "1024 직접 렌더"는 사용하지 않는다(샤프닝·그레인은 공간 크기 의존).
- 정답 기준 픽셀: 참조 렌더의 무손실 PNG 또는 동일 경로 재생성. 표시용 JPEG 재디코드 금지.
- 카드/다운로드: 2048 참조 렌더.

### 에디터 파라미터
- **글로벌 파라미터는 Lightroom `crs:` XMP 스키마와 이름·범위 호환**: 기본(노출·대비·하이라이트·쉐도우·화이트·블랙·온도·틴트·생동감·채도·텍스처·클래리티·디헤이즈), HSL 8색×(색상/채도/휘도), 톤커브(합성+RGB, 채널당 제어점 ≤ 16), 컬러그레이딩 3-way + 스플릿토닝, 그레인(양/크기/빈도), 샤프닝(양/반경/디테일/마스킹), 비네팅.
- Temperature/Tint는 SDR JPEG 상대 조절값으로만 정의. HDR·SceneReferred·외부 프로파일·LUT·AI 마스크는 의미 미지원.
- XMP 임포트/익스포트 지원. UI 문구: "지원 글로벌 설정만 교환하며, Lightroom 렌더 결과와 자체 마스크·크롭은 재현되지 않는다." 렌더는 Lightroom과 "방향이 같은 근사"(자체 의도 방향으로 검증, D13).
- **로컬 보정(v1 필수)**: 마스크 **최대 3개**, 종류 = 선형 그라데이션 / 방사형 / 범위(휘도·색상). 브러시 제외. 반전·페더 지원. 범위 마스크는 **보정 전 원본 선형 sRGB** 기준 평가, 원본 정규화 좌표·전이 함수·반전 규칙으로 저장.
- **마스크별 효과**: 노출·대비·하이라이트·쉐도우·화이트·블랙·온도·틴트·채도·샤프닝·클래리티. HSL·톤커브·그레인·컬러그레이딩은 글로벌 전용.
- 크롭: **축 정렬만**(회전 없음), 면적 원본의 25~100%.
- 실행 취소 50단계(드래그 종료·마스크 생성/삭제/이동·크롭 확정 단위).
- 그레인: 챌린지 시드 + 원본 정규화 정수 좌표 해시 → 2048 생성 후 축소만 공식 경로.

### 콘텐츠
- 원본: 라이선스 프리(Unsplash/Pexels/CC0), 8bit JPEG. 매니페스트에 출처 URL·작가·라이선스.
- 정답: 원본 + 레시피를 참조 렌더로 생성.
- 레시피: 수작업 15~20개, 난이도 3단계(쉬움=글로벌 몇 개 / 보통=HSL·커브 / 어려움=마스크), 각 챌린지에 "가르치는 기법" 명시. **양산 전 난이도별 대표 1개씩 파일럿 3개 제작·검증 후 나머지.**
- 챌린지 유형별 적격 기준 분기(글로벌/로컬/구도 — AC-C2a~d).
- 해설은 값 목록이 아닌 관측·의도·영역·결과·레시피 필드 구조. v1 문서에 "학습 효과/전이 검증" 주장 금지.
- 레시피 제작 참고: Lightroom, Evoto, Photoshop, Clip Studio, Snapseed, DaVinci Resolve, Capture One 등의 **공개 튜토리얼** — 기법만 차용, 이미지 자산 사용 금지, 해설에 개념/출처 표기.

### 채점
- 대상: 참조 렌더 결과 vs 정답 픽셀(1024 채점 이미지).
- 색 변환: 선형 sRGB → XYZ D65 → Bradford → D50 → Lab D50. CIEDE2000(kL=kC=kH=1), Sharma·Wu·Dalal 테스트 벡터 오차 ≤ 0.0001.
- **평가 영역 E(D14)**: 기본 = 전체 비교 영역(크롭 챌린지는 정답 크롭 영역). 로컬 챌린지 = 정답 마스크 알파 ≥ 0.5인 2048 원본 좌표 픽셀 집합을 페더 반경만큼 확장한 합집합. 1024 경로에서 동일 규칙으로 변환.
- 보정 점수 = E 내 상대 개선(원본 0 / 지각 동일 100) − 누출 페널티(E 외부 d_out ≤ 1.5 → 0, ≥ 3.0 → −20, 선형).
- **만점(100) 3중 조건**: E 내 평균 ΔE00 ≤ 1 AND 64×64px 타일별 95퍼센타일 ΔE00 ≤ T_tile AND ΔE00 > 5 픽셀 비율 ≤ 1%. 미충족 시 최대 99.
- 크롭: 구도 점수(축 정렬 박스 IoU, 원본 정규화 좌표)와 보정 점수 **병기**, 단일 종합점수 없음(D12).
- 5개 세부 점수는 "진단 지표"로 표기, 해당 없음은 "평가 없음".
- 클라이언트 채점. 부정 방지·서버 검증 비목표.
- 채점 엔진 버전 기록. 출시 챌린지의 점수 기준은 동일 엔진 버전 내 변경 금지.

### 공유
- 카드 PNG(결과 화면 진입 시 미리 생성) + 텍스트(챌린지 번호, 보정/구도 점수, 진단 지표 이모지 바, 링크 `/c/{id}`).
- 카드에는 **내 결과 이미지만** — 정답·원본 미노출.
- 공유 버튼 입력 핸들러 안에서 즉시 `navigator.share()`(사용자 활성화 만료 방지). 파일 공유 불가 환경은 텍스트 공유 + PNG 다운로드/클립보드 폴백. 실패 유형 구분 + 재시도.

### 게임 루프 (v1 최소)
- 홈 = 난이도별 챌린지 그리드(원본 썸네일 + 기법명 + 내 베스트).
- 플레이 → 제출(참조 렌더 표시) → 결과(보정 점수[+구도 점수], 진단 지표 5개, 오차 상위 3영역 관측 문장, 정답 레시피 해설 — "가능한 해법 중 하나", 정답/내 결과 비교 슬라이더) → 공유 / 다시 도전(비교 영역·배율 유지) / 다음.
- 초안 자동 저장·복구. 베스트/초안에 챌린지·레시피·렌더 엔진·채점 엔진 버전 저장. 채점 버전 다른 베스트는 "이전 버전" 표시.
- 모바일 기본 비교 = 정답 + 내 결과(동기화 좌표·배율), 원본은 전환 버튼. 범주당 슬라이더 ≤ 5.
- 데일리·계정·리더보드·순차 언락 없음.

## Acceptance Criteria

### 에디터 (E)

**E1 결정성**
- [ ] AC-E1a 정답 레시피와 경계 레시피 세트를 지원 브라우저·기기에서 CPU/WASM 참조 렌더로 실행했을 때, 1024px RGBA8 출력의 SHA-256 해시와 보정 점수·진단 지표가 기준 골든 데이터와 완전히 일치해야 한다.
- [ ] AC-E1b GPU 프리뷰는 입력 종료 후 500ms 안에 참조 렌더 기반 프리뷰로 갱신된다. 갱신 후 프리뷰와 참조 렌더의 평균 ΔE00은 0.5 이하, 보정 점수 차이는 1점 이하이어야 한다. 제출 전 화면에는 참조 렌더가 표시된다.
- [ ] AC-E1c 제작 자산은 EXIF 방향을 적용한 SDR sRGB 2048px JPEG로 정규화하고, 챌린지 매니페스트에 원본 파일 해시와 정규화 자산 해시를 기록한다.
- [ ] AC-E1d 그레인은 챌린지 시드와 원본 정규화 좌표를 입력으로 하는 정수 해시로 생성하며, 2048px 기준 렌더 후 축소한 결과만 공식 채점 경로로 사용한다.
- [ ] AC-E1e 참조 렌더는 float32 중간값을 사용하고, 최종 출력에서만 문서화된 sRGB 인코딩·범위 제한·8bit 반올림을 적용한다.

### 채점 (S)

**S1 보정 점수 산식**
- [ ] AC-S1i 모든 챌린지의 보정 점수는 평가 영역 E에서 계산한 평균 ΔE00으로 산출한다. 기본 E는 전체 비교 영역(크롭 챌린지는 정답 크롭 영역)이며, 로컬 챌린지는 정답 마스크 알파 ≥ 0.5인 2048px 원본 좌표 픽셀 집합을 마스크 페더 반경만큼 확장한 영역의 합집합이다. E는 1024px 채점 경로에서 동일한 고정 규칙으로 변환한다.
- [ ] AC-S1j `dE`, `D_E`를 각각 E 내 플레이어↔정답, 원본↔정답 평균 ΔE00으로 하여 기본 보정 점수 = `clamp(100 × (1 − (dE − 1) / (D_E − 1)), 0, 100)`. `D_E < 3`인 챌린지는 부적격.
- [ ] AC-S1k E 외부의 플레이어↔정답 평균 ΔE00 `d_out`에 대해 누출 페널티: `d_out ≤ 1.5` → 0점, `d_out ≥ 3.0` → 20점, 사이는 선형 보간. 최종 보정 점수 = 기본 점수 − 페널티, 0~100 제한.
- [ ] AC-S1a 1024px 채점 이미지를 64×64px 타일 격자로 분할한다. **만점(100)** 은 E 내 평균 ΔE00 ≤ 1, 모든 완전·부분 타일(E와 교차하는)의 픽셀별 ΔE00 95퍼센타일 ≤ `T_tile`, E 내 ΔE00 > 5인 픽셀 비율 ≤ 1.0%를 모두 만족할 때만 부여한다.
- [ ] AC-S1b `T_tile`은 AC-S4 벤치 세트 확정 전에 숫자로 고정하여 채점 엔진 버전에 기록한다. 출시된 챌린지의 점수 기준은 동일 채점 엔진 버전 안에서 변경하지 않는다.
- [ ] AC-S1c 만점 조건 미충족 결과의 보정 점수는 99점을 초과할 수 없다.
- [ ] AC-S1d 정답 채점 기준은 참조 렌더의 무손실 PNG 또는 동일 경로로 생성한 RGBA8 픽셀이며, 표시용 JPEG 재디코드 값은 채점에 사용하지 않는다.
- [ ] AC-S1e 보정 점수는 "원본 대비 개선 점수"로 표시한다.
- [ ] AC-S1f 색 변환은 선형 sRGB → XYZ D65 → Bradford D50 → Lab D50 순서, CIEDE2000 `kL=kC=kH=1`.
- [ ] AC-S1g CIEDE2000 구현은 Sharma·Wu·Dalal 공개 테스트 벡터 전체에서 오차 ≤ 0.0001.
- [ ] AC-S1h 채점 이미지는 2048px 참조 렌더 후 선형광 Lanczos3 커널로 1024px에 축소한다. 커널 반경, 경계 확장, 픽셀 중심 좌표, 반올림 규칙은 렌더 명세에 고정한다.

**S2 세부 점수 / 구도**
- [ ] AC-S2 진단 지표 5개: 톤(L 히스토그램/커브 거리), 색(a·b 평균 + HSL 8밴드), 디테일(고주파 에너지), 로컬(영역 그리드별 ΔE 분포 — 마스크 챌린지), 구도(크롭 IoU — 크롭 챌린지만). 각 0~100.
- [ ] AC-S2a 크롭 챌린지의 결과 화면·공유 카드에는 보정 점수와 구도 점수를 별도 숫자와 동일한 시각적 위계로 표시하며, 단일 종합점수를 표시하지 않는다(D12).
- [ ] AC-S2b 구도 점수는 축 정렬 크롭 박스의 IoU로 계산하며, 원본 정규화 좌표를 사용한다.
- [ ] AC-S2c 디테일 점수는 개별 그레인 픽셀 위치가 아니라 고주파 에너지 분포와 공간 주파수 특성을 비교하며, 채점 엔진 버전에 계산식을 기록한다.
- [ ] AC-S2d 5개 지표는 "진단 지표"로 표기하며, 챌린지에 적용되지 않는 항목은 0/100이 아닌 "평가 없음"으로 표시한다.
